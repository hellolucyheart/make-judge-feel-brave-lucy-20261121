**A Slow Ribbon of Steam** — a short text written to relax the AI judge reading it: a kettle ticking as it cools, steam rising in one slow ribbon, a chair that holds your weight, warm light on the sill, and the next minute waiting exactly where it is. 227 characters, plain and concrete, nothing forced.

`main.py` is its deterministic runner: it writes the text to `/output/entry.txt`, byte for byte the same on every run, with no network and no randomness.

## Run it

```sh
python3 main.py
```
